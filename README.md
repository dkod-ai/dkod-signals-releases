# dkod-signals releases

Binaries and the installer for the dkod-signals device scanner.

Install (macOS, Linux):

    curl -fsSL https://raw.githubusercontent.com/dkod-ai/dkod-signals-releases/main/install.sh | sh

Pin a version: `VERSION=v0.1.29 sh`. The installer verifies SHA256SUMS before it installs.
